Core Architecture

7-State Deterministic State Machine

Every task transitions through an audited, verifiable workflow.

1. UNDERSTANDINGParses file tree, extracts AST functions, imports, and symbol references.
2. INVESTIGATINGGenerates 20-section architectural finding report with diagnosed failures.
3. PLANNINGBuilds step-by-step remediation plan with verified target files.
4. APPROVAL GATEHuman Gate: Execution pauses. Human reviews plan & clicks 'Approve'.
5. IMPLEMENTINGApplies unified diffs in isolated execution workspace.
6. VERIFYINGRuns test suites, verifies zero regressions, diagnoses and heals remaining bugs.
7. REVIEWINGPresents Monaco Diff Editor, explains changes, enables 1-click Push & PR.

Safety & Governance

Enterprise-Grade Security Sandbox

Zero unvetted changes, zero unauthorized command execution.

🚫
Command Allowlisting
Strictly blocks dangerous binaries: rm, del, shutdown, curl | bash, git push --force. Only approved test runners (pytest, jest, vitest) execute.
🔒
Directory Isolation
Execution is strictly confined to task workspace boundaries. Traversal attempts (../) trigger immediate sandbox abort.
👥
Zero-PAT GitHub Auth
Developers never hardcode or share GitHub personal access tokens. Tasks authenticate via secure session tokens with isolated ephemeral permissions.
📊
Audit Log Trail
Every thought, tool invocation, diff application, and test stdout is indexed in SQLite/PostgreSQL with timestamps for total auditability.
