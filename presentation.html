State 4: Human-in-the-Loop

DevPilot halts execution. It presents the exact planned diffs. Zero code changes are applied without human consent.

State 6: Bounded Self-Healing

Executes actual test binaries. If tests fail, tracebacks are fed back into IBM Bob to auto-heal the patch (max 3 retries).

🛡️ Zero-Trust Security

Restricted Sandbox Jail & Secret Guardrails

Preventing malicious code injection, process escapes, and token exfiltration.

🔒 Binary Allowlist

Only approved test binaries execute: pytest, npm test, cargo test, go test.

🚫 Dangerous Command Denylist

Blocks destructive operations: rm -rf, del, curl | bash, git push --force.

Scans and redacts ghp_*, sk-*, and JWT tokens before any telemetry is sent to client screens.
