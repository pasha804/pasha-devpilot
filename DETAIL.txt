2. 30-SECOND ELEVATOR PITCH
--------------------------------------------------------------------------------
"Most AI coding assistants only write code snippets inside an editor and leave 
the messy debugging, broken tests, and git conflicts to the developer. 
Pasha DevPilot is different. Built as a production-grade extension for IBM Bob, 
DevPilot takes a GitHub issue or repository defect, builds an AST symbol graph, 
diagnoses the root cause, requests human approval, applies unified diffs inside 
a locked-down sandbox jail, and autonomously self-heals by running real unit 
tests until they turn green. Once verified, it ships a clean Pull Request 
directly to GitHub. It's not a chatbot—it's an autonomous AI software engineer."

3. 7-STATE MACHINE AT A GLANCE
--------------------------------------------------------------------------------
Stage 1: UNDERSTANDING         -> Clones repo into sandbox jail, parses AST syntax tree
Stage 2: INVESTIGATING         -> Runs test harness, isolates root cause with IBM Bob
Stage 3: PLANNING              -> Generates multi-file step-by-step implementation plan
Stage 4: WAITING_FOR_APPROVAL  -> HUMAN-IN-THE-LOOP GATE: Pauses execution until approved
Stage 5: IMPLEMENTING          -> Applies unified diff patches in isolated sandbox
Stage 6: VERIFYING             -> Runs real pytest suite; self-heals up to 3 attempts
Stage 7: REVIEWING / SHIP      -> Monaco Diff Editor + automated GitHub Pull Request

5. SANDBOX SECURITY GUARDRAILS
--------------------------------------------------------------------------------
- Directory Traversal Guard: Blocks any path containing "../" or outside sandbox root.
- Command Allowlist: Only approved binaries execute (pytest, npm test, git).
- Prohibited Commands: rm, del, format, shutdown, curl | bash, wget | sh.
- Blocked Git Actions: git push --force, git clean -f, git reset --hard.
- Secret Masking: ghp_*, sk-*, and JWT tokens automatically redacted in all UI logs.

6. ONE-CLICK LOCAL LAUNCH
--------------------------------------------------------------------------------
Windows : .\start.bat
Manual  :
  Terminal 1 (Backend) : python -m uvicorn apps.api.main:app --host 0.0.0.0 --port 8000 --reload
  Terminal 2 (Frontend): cd apps/web && npm run dev
Docker  :
  docker build -t pasha-devpilot-api -f apps/api/Dockerfile .
  docker run -p 8000:8000 --env-file .env pasha-devpilot-api
